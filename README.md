# Primitive DB

Консольная имитация базы данных на Python. Таблицы и данные хранятся в JSON-файлах.

## Установка

```bash
uv sync
```

Установка как отдельной команды:

```bash
uv build
uv tool install dist/primitive_db-<версия>-py3-none-any.whl
```

## Запуск

```bash
uv run database
```

или, после установки пакета:

```bash
database
```

## Управление таблицами

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | создать таблицу |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя_таблицы>` | удалить таблицу |
| `help` | справочная информация |
| `exit` | выход из программы |

Поддерживаемые типы: `int`, `str`, `bool`. Столбец `ID:int` добавляется автоматически.

Пример:

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
```

## CRUD-операции

| Команда | Описание |
|---|---|
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | создать запись |
| `select from <имя_таблицы>` | прочитать все записи |
| `select from <имя_таблицы> where <столбец> = <значение>` | прочитать записи по условию |
| `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` | обновить записи |
| `delete from <имя_таблицы> where <столбец> = <значение>` | удалить записи |
| `info <имя_таблицы>` | информация о таблице |

Строковые значения пишутся в кавычках, логические — `true` / `false`. `ID` генерируется автоматически.
В `set` можно перечислить несколько столбцов через запятую, в `where` — несколько условий через `and`.

Данные каждой таблицы хранятся в отдельном файле `data/<имя_таблицы>.json`.

Пример:

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок и декораторы

- `handle_db_errors` — перехватывает ошибки (несуществующая таблица, некорректные значения, отсутствующий файл) и выводит понятное сообщение вместо падения программы.
- `confirm_action` — перед удалением таблицы (`drop_table`) или записей (`delete`) запрашивает подтверждение. Операция выполняется только при ответе `y`.
- `log_time` — выводит время выполнения `insert` и `select`.
- `create_cacher` — замыкание для кэширования: результаты одинаковых запросов `select` к одинаковым данным берутся из кэша.

Пример:

```
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.

>>>Введите команду: select from users
Ошибка: Таблица "users" не существует.
```
